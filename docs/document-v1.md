# Whiteboard document v1

A document has documentVersion 1.0.0, stable local ASCII id, units css-px and objects in painter order (earlier first). Every shape/text/image/formula/connector/freehand/group/embedded-activity object owns a stable unique local ASCII ID and nullable groupId. Object identity is independent of canvas handles. Group membership references group objects; acyclic parent chains define the coordinate hierarchy. Groups are transform containers, not implicit clipping regions or stacking contexts. Painter order is the global objects array, including descendants; groups do not reorder their children.

Geometry x/y is top-left position in parent local coordinates, or document coordinates if ungrouped; width/height are positive local sizes. Rotation is radians [-pi,pi] about local origin; scaleX/scaleY are positive [.01,100]. No reflection, skew or perspective. Local affine matrix is T(x,y) R(rotation) S(scaleX,scaleY); world matrix multiplies ancestor matrices in that order. worldTransform returns [a,b,c,d,e,f], applying x'=a*x+c*y+e and y'=b*x+d*y+f. Computed matrices are ephemeral, not wire data, and floating-point trigonometry may differ in last bits across engines. Every composed component must be finite and within +/-1e12. Positions range +/-1e6, dimensions .001..1e6. These logical CSS pixel units are independent of physical device pixels and host zoom.

Text uses ContentNode (including recursive rich composition); image requires image ContentNode with shared AssetRef and alt/attribution semantics; formula requires math ContentNode, retaining tex/mathml source and accessibility content. No DOM nodes, HTML canvas objects, data blobs or asset bytes are serialized. This package never resolves/fetches assets or evaluates formulas/code. Asset permission, integrity and media policy belong to the host. Shapes rectangle/ellipse/diamond have closed stroke/fill/width/opacity style; freehand uses local nonnegative points within its bounding box and pressure [0,1]. Stroke width is local and therefore transformed with the object.

Connectors have from/to normalized bbox anchors [0,1]^2 and directed boolean. Non-null objectId references any non-connector object; anchors then refer to that target's local bounding box, transformed through its world matrix. Null references use connector's own bbox as the fallback. Hosts route connectors; this document does not store vendor routing handles. Deleting or grouping referenced objects is action-policy work in whiteboard#2. IDs cannot be inferred from geometry.

Embedded activities contain authored Protocol ActivitySpec, not an instantiated engine or snapshot. This initial schema rejects recursively embedded whiteboard activities; other nested activities still require their domain schema, semantic, capability and policy checks in Core before instantiation. The teaching fixture contains learner quiz questions only, without solutions. No renderer or secure assessment promise follows from structural embedding.

Limits: 1000 objects, 1000 points per stroke, 20000 total points; JSON2 MiB, depth32, collection1000, string100000, nodes50000. ContentNode and Protocol validation are offline, with no remote schema loading. Derived transform validation caches ancestors once. Non-JSON values, invalid geometry, duplicates, dangling connectors/groups, cycles and unknown fields fail with safe static diagnostics. normalizeDocument returns copied, deeply frozen JSON only after a trusted synchronous validator accepts it.

Viewport/zoom/pan, selection, pointers, gestures, editor handles and user presence are host ephemeral state and rejected in the persistent document. They must not be attached to it or serialized through this schema. No headless actions/history, rendering, snapshots, collaboration, implicit nested engine loading or npm release is added by this first issue. Shared contracts remain unchanged; optional domain-owned document schema is recorded in improvement-proposals/decisions/whiteboard-document-v1.md.
